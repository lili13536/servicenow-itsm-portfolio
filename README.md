# ServiceNow ITSM Practice Project
## Overview

Hands-on practice project using a ServiceNow Personal Developer Instance (PDI) to build practical experience with Incident Management — the core ticketing workflow used across most IT Support, Systems Analyst, and Service Desk roles. Built to demonstrate familiarity with the platform that dominates enterprise ITSM.

## What I Did :computer:
Set up a ServiceNow Personal Developer Instance from scratch
Worked through incident tickets across multiple categories (network, hardware, access, application)
Practiced the full incident lifecycle: triage → categorization → prioritization → resolution
Identified and corrected a misprioritized, SLA-breaching ticket
Documented before/after states and reasoning for each ticket worked

## Skills Demonstrated :stars:
Incident categorization and prioritization (Impact/Urgency/Priority matrix)
SLA awareness and breach identification
ITSM ticket lifecycle management (New → In Progress → Resolved)
Ticket triage and troubleshooting documentation (work notes, resolution notes)
ServiceNow navigation (agent view vs. self-service view)
